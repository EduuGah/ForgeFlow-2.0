# 05 — UX/UI

## Design direction

ForgeFlow should look like a polished fitness product, not an AI-generated dashboard.

Avoid:
- excessive cards
- excessive rounded containers
- giant empty dashboards
- aggressive gradients
- meaningless decorative icons
- fake metrics
- fake testimonials
- excessive glassmorphism
- dense desktop layouts copied into mobile
- unnecessary animations

## Active workout priority

The active workout screen should prioritize:
1. current exercise;
2. current/previous sets;
3. weight/reps entry;
4. set completion;
5. rest timer;
6. next exercise;
7. finish workout.

Input must be optimized for one-handed touch use.

## Motion

Use purposeful motion:
- set completion feedback
- PR celebration
- goal completion
- screen transitions
- skeleton loading

Avoid motion that slows repetitive logging.

## Accessibility

- readable type
- sufficient contrast
- touch targets appropriate for mobile
- support dynamic text where practical
- never communicate state by color alone
- clear validation messages

## Data visualization

Charts must answer questions:
- Am I getting stronger?
- Is my volume increasing?
- How consistent am I?
- Which exercises improved?
- How close am I to my goals?

Every chart should have a useful empty state.
